# Firmware

Ready to flash, built from [`zmk-config/`](zmk-config) against ZMK v0.3 for the `nice_nano_v2` board (the SuperMini nRF52840 is pin-compatible).

| File | Goes on |
|---|---|
| `settings_reset.uf2` | both halves, once, before the first flash |
| `air75_split_left.uf2` | left half |
| `air75_split_right.uf2` | right half (it talks to the computer) |

1. Double-tap the reset button on a half: it shows up as a USB drive.
2. Drop `settings_reset.uf2` on it. Repeat for the other half.
3. Do the same with `air75_split_left.uf2` on the left half and `air75_split_right.uf2` on the right.
4. Switch both on. They find each other; then pair the keyboard with your computer (Fn + Q for profile 1).

To change the keymap: copy the contents of `zmk-config/` into its own GitHub repository and push. GitHub Actions builds the same three files. The keymap is `zmk-config/boards/shields/air75_split/air75_split.keymap`; the animated screens are in `zmk-config/src/air75_oled/`.

`zmk-config/` is generated by `cad/gen_zmk.py` (pins and key positions come from the case model), so edit the generator if you want a change to survive `make`.

More: [firmware section of the build guide](../docs/BUILD.md#firmware).
